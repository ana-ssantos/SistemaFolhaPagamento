# Projeto Sistema de Folha de Pagamento (UC Dual)

Este projeto foi desenvolvido em Java para simular o cálculo de salários de diferentes tipos de colaboradores de uma empresa.

O sistema permite cadastrar colaboradores, armazenar suas informações em um array e calcular o salário de acordo com o tipo de vínculo:
- Colaborador Padrão
- Colaborador Comissionado
- Colaborador por Produtividade

--> Estrutura do Projeto
- Colaborador: classe principal que reúne as informações básicas dos funcionários.
- ColaboradorPadrao: calcula o salário sem adicionais.
- ColaboradorComissionado: adiciona comissão sobre vendas ao salário.
- ColaboradorProducao: adiciona bônus de produtividade ao salário.
- SistemaFolha: responsável pela execução do programa.
